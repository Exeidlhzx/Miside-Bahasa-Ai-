Cara Install VoicePack

1. Buka Library MiSide di Steam

Buka Library di Steam, cari game MiSide, lalu klik ikon Gear seperti pada gambar di bawah.

<p align="center">
  <img src="https://d3o8hbmq1ueggw.cloudfront.net/6cgm8%2Fpreview%2F81023916%2Fmain_large.png?response-content-disposition=inline%3Bfilename%3D%22main_large.png%22%3B&response-content-type=image%2Fpng&Expires=1790242484&Signature=hldw15sRcFGRTXbfwDlbI80oszU35wS7HfffSZlz2S2MpeCHT1XHj2-bj5kTCXVL7Q25Zp1Yti2~DNpN2Ts5UQCWTkMxmZZ7p93NEOesX9zR-M2GHm-ZFVCofUYYhwyIHvmurxlklXoQadiKWLbXKx9WT1uh3zjS4G2bGvMzGGPUJ5ePuAXV1lrNEyJquMq916KwMP04z63gT~6D8LeFvDupz7weeoBTLdkx6ZJLTla9MedO8MgelXnn7KIN~vc2dfzx553f02NYD9qVHagJedMLYrumutx5P1W4YOF2qekdquvbhpVaZ3OcNcSfLbo2lUdl6o4oMsPKV6vN0dAilQ__&Key-Pair-Id=APKAJT5WQLLEOADKLHBQ" alt="Steam MiSide Library" width="500">
</p>---

2. Pilih Menu Manage

Setelah itu, arahkan kursor ke menu Manage seperti pada gambar.

<p align="center">
  <img src="https://raw.githubusercontent.com/Exeidlhzx/Miside-Bahasa-Ai-/refs/heads/main/dua.png" alt="Steam Manage Menu" width="300">
</p>---

3. Klik "Browse Local Files"

Pilih Browse Local Files untuk membuka folder instalasi MiSide.

<p align="center">
  <img src="https://raw.githubusercontent.com/Exeidlhzx/Miside-Bahasa-Ai-/refs/heads/main/tiga.png" alt="Browse Local Files" width="300">
</p>---

4. Buka Folder "Data"

Setelah File Explorer terbuka, cari dan buka folder bernama "Data".

<p align="center">
  <img src="https://raw.githubusercontent.com/Exeidlhzx/Miside-Bahasa-Ai-/refs/heads/main/empat.png" alt="Data Folder" width="300">
</p>---

5. Buka Folder "LanguagesVoice"

Di dalam folder "Data", buka folder "LanguagesVoice".

<p align="center">
  <img src="https://raw.githubusercontent.com/Exeidlhzx/Miside-Bahasa-Ai-/refs/heads/main/lima.png" alt="LanguagesVoice Folder" width="300">
</p>Setelah itu, paste file VoicePack yang sudah kamu download ke dalam folder "LanguagesVoice".

Kemudian, extract file tersebut di dalam folder "LanguagesVoice".

Setelah proses ekstraksi selesai, kamu akan menemukan folder baru bernama:

Miside VoicePack

Folder tersebut berisi beberapa folder dan file lainnya.

«Jangan mengubah atau memindahkan isi folder tersebut.»

Kamu juga boleh menghapus file ZIP yang sudah diekstrak jika sudah tidak diperlukan.

<p align="center">
  <img src="https://raw.githubusercontent.com/Exeidlhzx/Miside-Bahasa-Ai-/refs/heads/main/Uhhh.png" alt="Hasil Ekstraksi VoicePack" width="300">
</p>---

6. Pastikan Struktur Folder Sudah Benar

Setelah selesai, pastikan folder "Miside VoicePack" berada langsung di dalam folder "LanguagesVoice".

Struktur foldernya harus kurang lebih seperti ini:

LanguagesVoice/
├── English/
├── French/
├── ...
└── Miside VoicePack/
    ├── ...
    ├── ...
    └── ...

«⚠️ Penting: Jangan menghapus, mengganti nama, atau memindahkan folder bahasa bawaan seperti "English", "French", dan folder lainnya.»

Jika folder "Miside VoicePack" sudah berada di dalam "LanguagesVoice", berarti proses instalasi VoicePack sudah selesai.
